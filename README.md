# Freakins - Contemporary Denim & Streetwear Experience

A modern, high-performance eCommerce web application built for next-generation denim and streetwear lifestyle brands. Featuring fluid animations, interactive fit guides, an intuitive shopping bag experience, and a real-time brand customizer laboratory.

---

## 🌟 Overview

This web platform delivers a sleek, responsive shopping destination inspired by modern Gen-Z streetwear culture. Designed with high-contrast aesthetics, dynamic promotional tickers, and curated collections spanning viral fits, cargo denim, and premium tailoring.

### Key Highlights

- **Viral Silhouette Showcase**: Curated categories featuring Baggy Skater Denim, Tactical Parachute Cargos, Korean Slouchy Pleated Trousers, and Structured Denim Corsets.
- **Interactive Denim Fit Guide**: Visual breakdown of rises, leg openings, stretch profiles, and styling recommendations for all body types.
- **Dynamic Brand Customizer Lab**: Live in-browser theme customization enabling instant updates to brand names, primary color palettes, currency formats, and announcement ribbons.
- **Quick Cart & Wishlist Drawer**: Slide-out shopping bag and saved-items drawers with real-time tax, shipping, and discount computations.
- **Responsive Navigation**: Desktop mega-menus with fit filters, category highlights, and search autocomplete, alongside a mobile-first drawer navigation.
- **Instant Vercel Compatibility**: Configured with pre-tuned SPA rewrites for one-click deployment.

## 🛠️ Technology Stack

- **Framework**: [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Deployment**: [Vercel](https://vercel.com/) (Single-Page Application configuration via `vercel.json`)

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (version 18 or higher recommended)
- `npm` or `yarn`

### Installation

1. Clone or download the repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
   cd YOUR_REPO_NAME
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the local development server:
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` (or the URL printed in your terminal) in your browser.

4. Build for production:
   ```bash
   npm run build
   ```

---

## ☁️ Deployment on Vercel

1. Push this repository to GitHub, GitLab, or Bitbucket.
2. Import the project in [Vercel](https://vercel.com).
3. The included `vercel.json` will automatically configure build output and client-side routing.
4. Click **Deploy**.
